SQL QUERIES
===========

These files contain standalone SELECT queries converted from the supplied
CREATE VIEW / CREATE OR ALTER VIEW definitions. They do not create views
and they do not export or extract results to CSV files.

Run each file in SQL Server Management Studio (SSMS) after confirming that
the database name in the USE statement matches your database.

IMPORTANT:
Q06_Loan_Default.sql is a placeholder because the supplied source script
contained only `0` for Q06, not an actual query. Add the verified Q06 query
before using that question in the project.

The foreign-key inspection query and unrelated USE BUSINESS_ANALYTICS
statements from the source file were not included in this Q01-Q15 folder.
